## Cómo trabajar en este proyecto

- Samuel es el diseñador UI/UX y desarrollador WordPress a cargo del proyecto
- El diseño se hace en **Figma**
- El desarrollo usa **Next.js + React** para el frontend y **PostgreSQL** para la base de datos
- Las referencias visuales están en el Miro: https://miro.com/app/board/uXjVGg4jEUs=/
- El PDF exportado del Miro está en `_referencias/miro-export.pdf`
- Ante cualquier duda de diseño, consultar primero `06-pantallas-referencia.md`
- Ante cualquier duda técnica, consultar primero `02-arquitectura-tecnica.md`
